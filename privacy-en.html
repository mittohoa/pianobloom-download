Privacy policy

Applies to the PianoBloom Android app (com.mittohoa.pianobloom), trial versions from this site and Google Play · Updated 21 Nov 2026

In short: PianoBloom keeps learning progress on the phone. No ads, no analytics or tracking tools, no account required, never asks for your child's name or photo. Cloud sync is an option parents turn on with a parent account (section 3b). The microphone (if a parent turns it on) is processed on the phone only and is never recorded, stored or sent.

Everything is in the app's private storage on the phone; learning data is encrypted with a key kept in Android's secure key store. The app turns off Android's automatic backup for this data.

2. Microphone

  • Used only when a parent allows the microphone in the parent area (off by default), for two things: "real piano via microphone" mode and the Sing the note challenge (from version 0.1.14).
  • Sound is analysed on the phone to recognise the notes your child plays or sings; never recorded, stored or sent. Only the result (which note) is used, just like the on-screen keyboard.
  • It can be turned off at any time in the parent area or in Android settings.

3. Network

  • Learning, playing and reports work fully offline.
  • Only when a parent taps Check for a new version (download-page builds), the app reads the public list of versions on GitHub. No child data is sent; GitHub may see the IP address, like any website. The Google Play build has no such button.
  • Tapping a link (download, this page) opens the phone's browser.
  • Linking two devices over Wi-Fi (trial, only when a parent turns it on): one device is the main device; the other enters its address and PIN, on the same home Wi-Fi or a personal hotspot. Only the numbers of the notes pressed/released, the keys to light and keep-alive signals travel between the two — no sound, names or learning data, no internet or server, nothing stored. The app accepts connections from local network addresses only; after several wrong PINs the main device stops; it also stops after 10 minutes without a second device.
  • Cloud sync runs only when a parent turns it on (section 3b).

3b. Cloud sync (optional, from version 0.1.12)

  • Off by default. A parent turns it on in Parent area → Cloud sync with a parent account (email + password). Children never create or use an account.
  • Sent when on: the parent account email; learner profiles (role, age band — no name, photo or birth date); lesson progress, attempts (notes played, right/not yet, hints), practice time, skill levels, review schedule; parent observations; songs played, tunes your child made up (notes and timing only) and the garden; connected piano info (source type, name, Bluetooth address of a MIDI piano if any).
  • Never sent: microphone sound, recordings, the error log, on-device settings.
  • Why: keep progress when changing phones, reinstalling, or learning on several family devices.
  • Where: Supabase servers (region ap-south-1, Mumbai, India). Encrypted in transit (HTTPS); each family can only read its own data (row-level access control).
  • Stop or delete: sign out to stop syncing (data on the phone stays); Delete account deletes all cloud data (section 5b).

4. Android permissions

  • Microphone — only for real-piano-via-microphone mode and the Sing the note challenge (section 2).
  • Bluetooth (find and connect nearby devices) — only to connect a Bluetooth MIDI piano when a parent searches for one. On Android 11 and older the system requires location permission to scan Bluetooth; the app does not use location.
  • Internet — for section 3.
  • Notifications — only when a parent turns on the Practice reminder (off by default): one notification a day at the chosen time, scheduled on the phone, no server.
  • Run at startup — only to reschedule the practice reminder after the phone restarts; nothing else.

5. Parents are in control

  • Settings, reports and privacy controls are behind the parent gate (a small challenge for grown-ups).
  • Export all data (JSON or CSV) in the Privacy card.
  • Music postcards: in the parent area, parents can send a tune their child made up as a MIDI file (notes and timing only, not a recording) through an app they choose. The app sends nothing by itself; children cannot send.
  • Permanently delete one profile or all data on the phone; uninstalling the app also deletes everything.

5b. Deleting an account

Only when a parent has created an account for cloud sync:

  • In the app: Parent area → Cloud sync → Delete account. All PianoBloom data in the cloud is deleted at once; the login is deleted too if PianoBloom created it.
  • Can't open the app? Email mittohoa@gmail.com or open an issue (give the account email; don't post your child's data). Requests are handled within 30 days.
  • Learning data on the phone is deleted by the parent in the Privacy card or by uninstalling.

5c. Feedback and the error log

  • When an error happens, the app keeps the last 20 errors on the phone (ids and emails masked). There is no automatic crash reporting and nothing is sent.
  • In Feedback & bug reports, parents write the message, preview it and choose to send it by email (to mittohoa@gmail.com) or another app. Device info and the error log are attached only when ticked.

6. Children

PianoBloom is for children aged 4–12 learning with, or with the consent of, a parent or guardian. The app has no chat, social features, leaderboards, ads or in-app purchases.

7. Changes and contact

When this policy changes, the date at the top changes and the release notes say so. Questions or requests: mittohoa@gmail.com or github.com/mittohoa/pianobloom-download/issues (please don't post your child's personal information there).
